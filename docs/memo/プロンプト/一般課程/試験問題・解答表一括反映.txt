添付または指定された生命保険一般課程の試験問題PDFおよび解答表を正本として、指定Vueファイルに設問タイトル・正解表示・確認済みの `rev` をまとめて反映してください。

対象Vueファイル:

- `resources/js/Pages/Ippan/Tests/<ファイル名>.vue`

対応する進捗表:

- `docs/memo/生命保険一般課程/Ippan-progress.md`

## 一般課程の問題構成

一般課程は全82問で、大学・専門・応用課程の49問構成とは異なる。問題PDFと解答表を正本とし、必ず実際の構成を確認する。問1〜30の既存 `questionRange` は仮の枠であり、PDFの見出し・空欄番号と異なる場合は修正する。問31〜82は `questionNumber` と各 item 末尾の問題番号コメントで対応を確認する。

| 問題番号 | Vueコンポーネント | 出題形式 | 反映単位 |
|---|---|---|---|
| 1〜30 | `QuestionTemp3`（通常11ブロック） | 語群から選ぶ穴埋め問題 | PDF上の見出し・空欄番号の範囲ごと |
| 31〜33 | `QuestionTemp1` | 4肢から誤っているものを2つ選ぶ問題 | 問題ごと |
| 34〜37 | `QuestionTemp1` | 誤っているものを1つ選ぶ問題 | 問題ごと |
| 38〜67 | `QuestionTemp2` | 正誤・訂正問題 | itemごと |
| 68〜82 | `QuestionTemp2` | A・B等の選択肢から選ぶ穴埋め問題 | itemごと |

- 問1〜30のブロック長・区切りは年度・フォームにより異なる。PDF上の見出しと空欄番号から毎回決定し、固定の範囲や既存Vueの `questionRange` を前提にしない。
- 問38〜67と問68〜82は同じ `QuestionTemp2` でも解答形式が異なる。`questionNumber` と item末尾の `//38`〜`//82` で範囲を確認する。
- 問1〜30は、PDFのブロック範囲に合わせて `QuestionTemp3` の `questionRange`、`contents`、`labels` の要素数、問題番号コメントを組み替える。表示仕様に関わるpropsや、問31〜82のコンポーネント設定は変更しない。

## 既存データの扱い

- `questionTitle`、`contents`、`labels`、`items`、`rev` がすでに入っていても完了扱いで読み飛ばさず、PDFと解答表に照らして問題番号ごとに再確認する。
- 一致した場合は `rev` を重複追加しない。必要に応じて既存の確認日を作業日に更新する。
- 不一致は試験問題PDFと解答表を優先して修正する。OCRだけで確定せず、該当ページと解答表を目視確認する。
- 指定範囲外の問題文、解説、関連問題、コンポーネント設定、レイアウトは変更しない。ただし問1〜30のPDF上のブロック範囲と既存 `questionRange` が不一致の場合に限り、ブロック構成の修正を許可する。

## 作業手順

### 1. 編集前に対応表を作る

問1〜82について、少なくとも次を問題番号単位で照合する。

- PDF上の設問タイトル
- 解答表の正解（記号または正誤）
- 語群・選択肢の文言
- Vue内のコンポーネント、`questionRange` または `questionNumber`、`questionTitle`、`labels`、`content`

`questionTitle` は見出しとして簡潔に入力する。PDF上の設問タイトルが末尾の「について」で終わる場合は、その「について」を省略する。ただし「〜についての」のようにタイトル途中に含まれる表現は省略しない。

### 2. 問1〜30（`QuestionTemp3`）を反映する

- PDFの各見出しに対応する空欄番号の開始・終了を読み取り、ブロックごとの `questionRange` を設定する。既存の `questionRange` と異なる場合は、`QuestionTemp3` を分割・結合してPDFどおりに組み替える。PDFに①・②等の区分があればタイトルにも残す。
- 各 `QuestionTemp3` の `contents` と `labels` は、`questionRange` に含まれる問題数と同数にする。各要素の末尾コメントもPDFの問題番号に合わせて付け直す。
- 解答表の記号を、問題番号コメント（例: `//1`）と一致する `labels` の添字に入れる。
- 語群から、各記号に対応する語句を確認し、同じ添字の `contents` に入れる。
- 配列の並びや語群の掲載順だけで対応付けない。範囲内の全問について「問題番号 / 正解記号 / 語句 / labels / contents」を突合する。
- `contents` の先頭に、値の前の独立行として `// rev: YYYY-MM-DD 確認済み` を置く。1つの `rev` は、その `questionRange` の全問を確認したことを表す。

### 3. 問31〜37（`QuestionTemp1`）を反映する

- `questionNumber` とPDFの設問番号を照合し、`questionTitle` を設定する。
- 解答表のア・イ・ウ・エ等の記号と `contents` の配列位置を対応付ける。選択肢数は実際の問題を正本とし、固定しない。
- 問31〜33は「誤っているものを2つ選ぶ」問題である。解答表に記載された2つの記号が誤りの選択肢なので、それ**以外**の選択肢を `正しい` とする。たとえば問31の解答が「1つ目: ア、2つ目: ウ」なら、イ・エを `正しい` とする。
- 問34〜37は「誤っているものを1つ選ぶ」問題である。解答表に記載された記号が誤りの選択肢なので、それ**以外**の選択肢を `正しい` とする。たとえば解答がアで選択肢がア・イ・ウなら、イ・ウを `正しい` とする。
- 解答表に記載された誤りの選択肢は `''`（空欄）とし、末尾の `//p` を残す。訂正内容・解説は入力しない。
- `contents` の先頭に `// rev: YYYY-MM-DD 確認済み` を追加しない。
- `正しい` にした行では末尾の `//p` を削除する。

### 4. 問38〜67（`QuestionTemp2` の正誤・訂正問題）を反映する

- 各 item の末尾コメント（例: `//38`）を正本として問題番号に対応付け、`questionTitle` をPDFの設問タイトルに設定する。
- 解答表で「正」の問題は `content: '正しい'` とする。
- 解答表で「誤」の問題は `content: ''`（空欄）とし、末尾の `//p` を残す。訂正内容・解説は入力しない。
- 解答表で「誤」の item には `// rev: YYYY-MM-DD 確認済み` を追加しない。「正」の item のみ、itemオブジェクトの先頭（`questionTitle` の前）に追加する。
- `正しい` の item では末尾の `//p` を削除する。

### 5. 問68〜82（`QuestionTemp2` の選択式穴埋め問題）を反映する

- item末尾の問題番号コメント（例: `//68`）を正本として、PDFの設問番号・設問タイトル・選択肢と照合する。
- 解答表の記号を各 item の `label` に設定し、その記号に対応する語句を `content` に設定する。
- `applyChoicePrefix="false"` のブロックでは、`content` に `A-`、`B-`、`C-` 等の接頭辞を付けず、語句のみを入力する。
- 既存の `applyChoicePrefix`、`useAnswerLabelForAll`、`label` の設定は、表示仕様に関わるため変更しない。必要な値だけを反映する。
- 各 item オブジェクトの先頭（`questionTitle` の前）に `// rev: YYYY-MM-DD 確認済み` を置く。すでにある場合は重複させない。

## 検証

1. 解答表を目視確認し、問1〜82の番号と正解をすべて読み取る。OCRだけでは確定しない。
2. 問1〜30は各 `questionRange` の実際の開始・終了番号、解答記号、語句を全件照合する。
3. 問31〜33は解答表の2つの誤り選択肢以外、問34〜37は解答表の1つの誤り選択肢以外が `正しい` になっていることを確認し、誤り選択肢は空欄であることを確認する。問38〜67は「正」が `正しい`、「誤」が空欄であり、「誤」に `rev` がないことを確認する。問68〜82は解答記号と語句を再照合する。
4. `QuestionTemp2` は配列位置だけで問題番号を判断せず、`questionNumber` と item末尾コメントの両方を確認する。
5. `rev` を集計する進捗表を更新する。通常は全82問を母数とし、`QuestionTemp3` は `questionRange` に含まれる問題数、`QuestionTemp1` は1問、`QuestionTemp2` は rev のある item を1問として数える。進捗表が存在しない場合は、`docs/memo/生命保険一般課程/Ippan-progress.md` を「全体 / ファイル別 / 未完了一覧」の構成で新規作成する。
6. 最後に `git diff --check -- <対象Vueファイル> <進捗表>` を実行する。進捗表を更新しない場合も、対象Vueファイルに対して実行する。

`YYYY-MM-DD` には作業日を入れる。
