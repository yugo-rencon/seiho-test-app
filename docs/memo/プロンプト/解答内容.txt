


Keiri202Xx の指定範囲を、添付の選択肢画像と照合して確認して
確認できたものだけ rev を入れ、進捗表も更新して。

対象:
- resources/js/Pages/Tests/Keiri/Keiri202Xx.vue
- docs/memo/生命保険講座/Keiri-progress.md

確認範囲:
- 問1〜20
- 問21〜24
- 問41〜50

作業ルール:
1. 添付画像の選択肢と、Vue ファイル内の answer / labels / label / content が一致しているか確認する
2. 一致している問題には `// rev: YYYY-MM-DD 確認済み` を追加する
3. rev の位置は Keiri2025a の書き方に合わせる
   - QuestionTemp4: 各 item の `answer` の直前
   - QuestionTemp3: `contents` 配列の先頭
   - QuestionTemp2 items: 各 item の `questionTitle` の直前
4. すでに rev がある問題には重複して追加しない
5. 指定範囲外は確認・修正しない
6. 不一致があれば、正しい値に修正してから rev を入れる
7. 判断できないものは勝手に rev を入れず、どこが不明か報告する

進捗表:
- 追加した rev 件数を Keiri-progress.md に反映する
- 全体の完了数/進捗率を更新する
- 対象ファイルの完了数/進捗率を更新する
- 未完了一覧から、今回 rev を入れた問題番号を除外する

注意:
- 余計な整形や unrelated な変更はしない
- 既存の未コミット変更は戻さない
- 最後に、追加した rev 件数、更新後の進捗、未完了一覧を簡潔に報告する
